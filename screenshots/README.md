# 截图说明 (Screenshots)

简体中文 · [English below](#english)

这个文件夹里有两组不同的界面截图。为了避免混在一起看不清楚，先说明各自是什么。

- **`ko/`：ARTEX 韩语版的真实 UI 截图。** 这是[`../README.ko.md`](../README.ko.md)（韩语
  版说明文档）引用的截图。只想看韩语版界面的话，打开 [`ko/`](ko/) 文件夹。
- **根目录下的 `*.png`：上游原版（中文版）的 UI 截图。** 为了能和上游仓库逐张对照，
  **原样保留**，保留的中文 README [`../README.zh.md`](../README.zh.md) 引用这些图片。
  当前的 [`../README.md`](../README.md)（本 fork 的简体中文说明）和
  [`../README.en.md`](../README.en.md) 都是精简过的概览文档，暂时没有嵌入任何截图。
- **`wx.png`：上游原作者的微信公众号推广图。** 为了让
  [`../README.zh.md`](../README.zh.md) 保持原样渲染而一并保留，与韩语版无关。

简单说：根目录下先看到的是中文截图，那是为了保留上游原样；**韩语版的界面截图在
[`ko/`](ko/) 里。** 这个仓库为什么要把原版一起保留（本地化透明度·方便与上游对照），
与防御·检测的定位是同一个思路，详细背景请参考根目录的 README。

## English

This folder holds two separate sets of captures. To keep them from looking mixed, here
is what each one is.

- **`ko/` — real UI of the Korean edition of ARTEX.** These are the screenshots used by
  [`../README.ko.md`](../README.ko.md) (the Korean-language README). For the Korean
  edition's screens, open [`ko/`](ko/).
- **The `*.png` files in the root — upstream (Chinese edition) UI captures.** They are
  **preserved as-is** so the fork can be diffed against the upstream repository 1:1, and
  the preserved Chinese README [`../README.zh.md`](../README.zh.md) references them. The
  current [`../README.md`](../README.md) (this fork's Simplified Chinese overview) and
  [`../README.en.md`](../README.en.md) are both trimmed-down overview docs and currently
  don't embed any screenshots.
- **`wx.png` — the upstream author's WeChat channel promo image.** Kept so that
  [`../README.zh.md`](../README.zh.md) still renders unchanged. It is unrelated to the
  Korean edition.

In short, the Chinese screens you see first in the root are there for upstream
preservation; the **Korean edition's screens live in [`ko/`](ko/).** See the root README
for why this fork keeps the originals alongside (localization transparency and upstream
comparison).
